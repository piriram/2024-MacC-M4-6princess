# Release Device Smoke Checklist

## 목적
실기기 필수 검증 항목만 빠르게 확인해 릴리스 직전 회귀를 줄인다.

## 기본 환경
- 최신 iPhone 1대
- 구형 iPhone 1대
- iPad 1대
- 앱 설치 후 첫 실행 상태

## 5분 스모크 시나리오
1. 권한 플로우
- 카메라 권한 요청 문구 노출 확인
- 사진 라이브러리 권한 요청 문구 노출 확인

2. 카메라 핵심 동작
- 카메라 진입 성공
- 전면/후면 전환 1회
- 촬영 1회

3. 누끼 및 편집
- 촬영 후 누끼 생성 성공
- 편집 화면 진입 및 기본 동작(브러시/이동) 확인

4. 저장/공유
- 사진 저장 성공 토스트/알림 확인
- 공유 시트 정상 오픈 확인

5. 목록/상세/수정
- 저장된 이미지가 목록에 반영되는지 확인
- 상세 화면 진입 후 수정 화면 이동 확인

## 실패 시 기록 규칙
- 단계: 권한 / 카메라 / 누끼 / 저장 / 공유 / 목록 / 상세
- 증상: 사용자 관찰 문구 그대로 기록
- 로그: Xcode 콘솔 핵심 5줄 캡처
- 재현 조건: 기기/OS/앱 빌드 번호

## 통과 기준
- 크래시 0건
- 저장 실패 0건
- 누끼 생성 실패 0건
- 필수 화면 전환(카메라→편집→저장→목록) 완료
